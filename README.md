# Smart Task Management System

## Features
- User Authentication
- Task CRUD APIs
- PostgreSQL Integration
- Real-time Notifications
- Analytics Dashboard
- Responsive Bootstrap UI

## Installation

```bash
pip install -r requirements.txt
python app.py
```

## PostgreSQL Setup

Create database:

```sql
CREATE DATABASE taskmanager;
```

Update credentials in config.py

## API Endpoints

- POST /api/tasks
- GET /api/tasks
- PUT /api/tasks/<id>
- DELETE /api/tasks/<id>
